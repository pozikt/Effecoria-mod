# Стеклянное бревно / ветви

## Материал
Petrified lightning trees — оплавленная древесина Φ-вспышки:
- **бревно** (`cube_column`): side + top
- **ветви** (`cross`): силуэт куста на прозрачном фоне

Палитра: чёрное стекло, ультрамарин, циан, редкое золото.

## Пайплайн
Эскиз → crop → nearest 16×16 → `textures/block/`
Скрипт: `scripts/pack_vitrified_wood.py`
