# Стеклянный песок (`vitrified_sand`) — редизайн

## Роль в биоме
Поверхность дюн / Φ-барханов. Зыбучий стеклянный песок: **мелкое зерно**, не комья земли.
Отличие от `vitrified_dirt`: больше блеска-осколков, ровнее «песчаный» шум.

## Палитра (как у земли)
| Роль | HEX |
|------|-----|
| База | `#080A10` … `#161A22` |
| Ультрамарин | `#1A2A6A` … `#3A5AB0` |
| Циан-блик | `#5EC8FF` |
| Φ-золото | `#C9A227` (редко) |

## Силуэт
База: ванильный [`sand.png`](../../vanilla_refs/sand.png) — зернистость песка, только материал → чёрное стекло.
