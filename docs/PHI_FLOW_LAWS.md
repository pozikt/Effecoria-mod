# Законы Эссенциальных Потоков (Φ-ток)

**Status:** runtime solver shipped (channels, contactors, couplers, matcher, accumulators, filaments). **Phase C inrush shipped**. **Phase D matcher shipped** (`phi_matcher` bridges Δω; imprinter pays cos(Δω)). Lex Loci edict language still planned.  
**Lore:** сформулированы Лонверами.  
**Related:** [FORMULAS.md](FORMULAS.md), [TECHNOMAGIC.md](TECHNOMAGIC.md), [LEX_LOCI.md](LEX_LOCI.md).

Φ-ток — поток эссентонов, не электронов. Он **не подчиняется суперпозиции** так, как электричество: заряд накапливается, поле не потенциально, есть резонанс и Ω-утечка. Законы Кирхгофа **не** переносятся на Φ-сети.

## Почему не Кирхгоф

| Причина | Следствие |
|---------|-----------|
| Φ-заряд накапливается в эссените | Σ I_in ≠ Σ I_out законно (ΔQ_Φ) |
| Φ-поле не потенциально | работа зависит от частоты Ψ-интенции, не только от «разности потенциалов» |
| Резонанс с ω устройства | усиливает или гасит полезный поток |
| Ω-диссипация | часть потока уходит в мнимую компоненту / Ад |

## Четыре закона

### 1. Сохранение Φ-заряда

$$
\sum I_{\Phi}^{in} = \sum I_{\Phi}^{out} + \Delta Q_{\Phi} + I_{\Omega}
$$

| Символ | Смысл |
|--------|--------|
| Σ I_in / Σ I_out | входящий / исходящий Φ-ток |
| ΔQ_Φ | изменение заряда в узле (эссенит, накопитель, ячейка) |
| I_Ω | утечка в Ω-пространство |

Эссентоны не появляются из ниоткуда и не исчезают: проходят дальше, копятся, или уходят в Ад.

### 2. Частотный резонанс

$$
P_{device} = P_{\Phi} \cdot \cos(\Delta\omega \cdot t)
$$

| Символ | Смысл |
|--------|--------|
| P_device | полезная мощность на устройстве |
| P_Φ | передаваемая Φ-мощность по каналу |
| Δω | \|ω_канала − ω_устройства\| |

Δω = 0 → устройство получает полную пользу. Расстройка → провал мощности, отражение потока, рост I_Ω. Один и тот же «Φ-вольт» делает разную работу для разных машин.

### 3. Охлаждение проводника

$$
T_{conductor} \approx T_{ambient} - k \cdot I_{\Phi}^{2}
$$

Обратный эффект Джоуля–Ленца: Φ-проводник **охлаждается** при токе. Шины не нуждаются в охлаждении; перегрев — у источников, несогласованных нагрузок и отражённой Φ. Мифрил: высокий k.

### 4. Ω-накопление

$$
\Omega_{level} \propto \sum I_{\Omega} \cdot t
$$

Долгая работа + утечки → критический Ω → очистка (демпфер / фильтр) или Ω-прорыв.

## Аналогия для инженеров (не модель)

| Электричество | Φ-энергия |
|---------------|-----------|
| Закон Ома | Частотный резонанс |
| Кирхгоф I | Сохранение Φ-заряда (+ΔQ, +I_Ω) |
| Кирхгоф II | **нет** прямого аналога |
| Джоуль–Ленц (нагрев) | Охлаждение проводника |
| — | Ω-накопление |

## Практика Φ-сетей башни

Инженер не считает «токи в узлах» как электрик. Он:

1. **Подбирает частоту** — Φ-ток должен резонировать с устройствами. Сеть делится на **частотные каналы** (как Wi‑Fi для энергии): типично `life`, `industry`, `defense`, `psi` (командный).
2. **Следит за Ω** — каждый узел потенциальная утечка; демпферы в ключевых точках.
3. **Учитывает накопление** — эссенитовые буферы сглаживают пики (inrush воскрешения = законный разряд ΔQ).

Беспроводной `PhiPower` (LOS) остаётся ближним излучением комнаты. Магистраль — граф проводников с именованными каналами. Силовой Φ и Ψ-команда (~7.8 Гц) **не** смешивают на одном канале.

## Игровая дискретизация (план)

| Символ | В рантайме (план) |
|--------|-------------------|
| I_Φ | Φ-такты / тик по ребру канала |
| ΔQ_Φ | заряд накопителя / ячейки |
| I_Ω | прирост Ω узла / реактора |
| ω | тег канала на шине / согласователе |
| cos(Δω·t) | penalty полезной мощности + вклад в I_Ω |
| k | таблица материала (мифрил > phi_bus) |

**Solver (план):** каждые N тиков — баланс закона 1 по каналам с учётом контакторов → P_device по закону 2 → при спросе выше бюджета канала сначала ΔQ, иначе shed / brownout → I_Ω копит Ω (закон 4). Не SPICE и не контурные уравнения Кирхгофа II.
