# Lex Loci — язык программирования башни

**Status:** design — full edict language not shipped. Physical Φ-circuitry playable ([PHI_FLOW_LAWS.md](PHI_FLOW_LAWS.md)). **Phoenix shed / E0.5 / Phase C inrush shipped**. **Phase D matcher shipped** (`phi_matcher` + Ψ-imprinter Δω penalty). **Phase G0 watchdog shipped** (re-shed while phoenix snapshot held; turrets autonomous). Full word editor = phase E.  
**Depends on:** [PHI_FLOW_LAWS.md](PHI_FLOW_LAWS.md), seals word grammar ([SEAL_PROGRAMMING.md](SEAL_PROGRAMMING.md)), tower facility (`TowerFacility`, console, Ψ-computer).  
**Roadmap:** Stage IV / Technomagic Era VI (nervous system atop Era IV–V reactors).

Lex Loci («закон места») — словесные **эдикты** для Ψ-компьютера. Не новый скриптовый язык и не Lua: тот же конвейер слов, что у печатей (`WHEN` / `IF` / `ELSE` / `LOOP` / `ORDO`), но субъекты — онтология башни (душа, каналы Φ, именованные машины, телеграфы).

## Зачем

Сейчас все потребители бьют в лучший `PhiPowerProvider`; revive проверяет только `hasPower`. Игрок не может гарантировать бюджет канала `life` в момент смерти. Lex Loci + частотные каналы закрывают это и дают гибкие сценарии поверх Законов Эссенциальных Потоков.

## Модель

**ECA:** событие → условие? → действие+ → пока?

```
КОГДА <событие> ЕСЛИ <условие>? ТО <действие>+ ПОКА <пока>?
```

Компиляция: текст → слова печатей + символы башни → AST → байткод на якоре.  
Тик: шина событий → подходящие эдикты → актуаторы (контакторы каналов, режимы машин, сигнал, автономия).

### Адресация

| Синтаксис | Значение |
|-----------|----------|
| `kind*` | все устройства вида в Φ-компоненте |
| `kind#имя` | названное в консоли / биркой |
| `шина:life` | именованный частотный канал |
| `душа` / `владелец` / `призрак` | привязки якоря |
| `телеграф:имя` | удалённый I/O |

Автодополнение: `TowerFacility.listMonitors` + имена каналов + телеграфы + привязки души → таблица символов в редакторе консоли.

## Канонический эдикт Феникса

Энергосбережение / приоритет жизни при смерти владельца:

```
КОГДА душа.мертва
ТО
  ОТКЛЮЧИТЬ шина:потребители
  ПИТАТЬ реген_камера*, пси_импринтер, инкубатор*, омега_демпфер
  СИГНАЛ ВКЛ
  турель* АВТОНОМ
```

Физика под эдиктом: разомкнуть чужие каналы → оставить `life` → разряд ΔQ накопителя на inrush сборки тела → согласователь держит Δω≈0 для импринтера → турели на локальных печатях (K_руны компьютера занята душой) → сторож повторяет топологию при потере heartbeat.

## Что ещё программировать (кроме Феникса)

Ниже — сценарии, которые Lex Loci должен уметь выражать. Часть цепляется к уже существующим системам башни; часть — к плановым приборам каналов.

### Оборона и тревога

| Эдикт (идея) | Событие → действие |
|--------------|-------------------|
| **Карантин купола** | купол.пробит / телеграф.тревога → купол БОЙ + турель* ВООРУЖИТЬ + СИГНАЛ |
| **Тихий режим** | душа.спит / ночь → турель* СНЯТЬ_С_БОЕВОГО, сонар СОН (экономия канала defense) |
| **Автономия при отъезде** | владелец.вне_башни ДОЛГО → турель* АВТОНОМ, портал ЗАКРЫТЬ |
| **IFF по телеграфу** | телеграф:застава.враг → defense ПОЛНЫЙ, climate ТУМАН (если есть) |
| **Перегрев турелей** | турель.перегрев* → ОТКЛЮЧИТЬ турель#эта, ПИТАТЬ турель#резерв |

### Ω и целостность

| Эдикт | Смысл |
|-------|--------|
| **Ω-страж** | Ω.крит → ОТКЛЮЧИТЬ industry, ПИТАТЬ омега_демпфер*, СИГНАЛ, при Ω.max — SCRAM реактор |
| **Целостность** | целостность.падает → СИГНАЛ владельцу (уже есть loci pain; эдикт добавляет действия сети) |

### Энергия и производство (не только revive)

| Эдикт | Смысл |

| **Резонансный карантин** | Δω.высок на life → ОТКЛЮЧИТЬ связь forge↔life до согласователя |

### Отказоустойчивость (аппаратно + эдикты)

| Механизм | Роль |
|----------|------|
| **Сторож** | нет heartbeat компьютера → принудительная топология Феникса (язык некому исполнять) |
| **Приоритетный коллектор** | при перегрузе канала всегда кормит `life` без эдикта |
| **Автономия турелей** | локальные печати на лафете (seal-automata), когда K_руны якоря занята |

## События и действия (черновик словаря)

**События:** `душа.мертва` / `душа.жива` / `душа.призрак`, `Ω.крит`, `реактор.scram`, `канал.перегруз`, `телеграф.тревога`, `купол.пробит`, `сторож.тишина`, `владелец.вне_башни`, `время.рассвет`.

**Действия:** `ОТКЛЮЧИТЬ` / `ПИТАТЬ` канал или kind*, `АВТОНОМ` / `ВООРУЖИТЬ` турелей, `СИГНАЛ`, `SCRAM`, `ЗАРЯДИТЬ` накопитель, `portal ЗАКРЫТЬ`, `climate <режим>`, `сонар СКАН`.

Слова расширяют datapack печатей (`seal_words` / будущий `loci_words`), не заменяют грамматику.

## Приборы (кратко)

Силовые: контактор канала, резонансный согласователь (Δω→0), эссенитовый накопитель (ΔQ), Ω-разрыв, Φ-нить (entity, не LivingEntity), приоритетный коллектор.  
Управляющие: Ψ-компьютер (хост), консоль (редактор), телеграф, Ψ-реле, сторож, сигнализация.

Детали физики — [PHI_FLOW_LAWS.md](PHI_FLOW_LAWS.md). Этапы внедрения — см. раздел ниже.
