# Server rules template (RU / EN)

Paste into Discord `#welcome` and `/rules` book on spawn. Edit before Phase C.

## RU

```
Официальный сервер Effecoria

1. Не гриферить чужие постройки и сундуки без согласия.
2. Чит-клиенты, дюпы, эксплойты — бан. Баги мода репортить в #bug-reports.
3. Уважение в чате: без хейта, доксинга, спама.
4. Донат = косметика и QoL. Силу (урон, Ψ, школы) за деньги не продаём и не просим.
5. Админы могут откатить гриф и варпнуть на ивенты сезона.
6. Версия мода — только рекомендованная с Modrinth / Discord.

Наказания: варн → мут → кик → бан (срок по тяжести).
```

## EN

```
Official Effecoria server

1. No griefing bases or chests without consent.
2. Cheats, dupes, exploits = ban. Report mod bugs in #bug-reports.
3. Be respectful: no hate, doxxing, spam.
4. Donate is cosmetics & QoL only. We do not sell (or accept requests for) power.
5. Staff may roll back grief and warp players for season events.
6. Use only the recommended mod version from Modrinth / Discord.

Sanctions: warn → mute → kick → ban.
```
