# Official server — phased monetization

The server is the **living canon** of Effecoria, not a random anarchy host.

**Policy:** cosmetics, seasons, QoL ranks — **never** pay-to-win (damage, Ψ, Φ, school power, exclusive strong spells).

## Phase A — Do not launch yet

Blocked until:

- [ ] [STAGE_I_FUNNEL.md](STAGE_I_FUNNEL.md) GO
- [x] Dedicated server smoke-tested with the mod
- [ ] Backup + restart procedure written
- [ ] Rules + ban policy drafted (RU+EN)

## Phase B — Whitelist (supporters / testers)

**Goal:** feedback and spectacle for streams, **no donate shop**.

| Setting | Value |
|---------|-------|
| Access | Whitelist: Initiate+ and invited testers |
| Economy | Survival + Effecoria progression only |
| Donate | Off |
| Resets | Allowed; announce |
| Mods | Effecoria + quality-of-life agreed list (map, voice, anticheat later) |

Ops:

- Weekly backup
- `#server-status` Discord channel
- Bug reports tagged `server`

Duration: ~4–8 weeks of stable interest, then Phase C.

## Phase C — Public server + cosmetics

Open when Phase B is stable and you can spend time/money on moderation.

### Sold (allowed)

| Product | Notes |
|---------|-------|
| School auras / trails | Particle cosmetics tied to school |
| HUD frames / nametag effects | Match Operator Boosty tier where possible |
| Titles | Lore titles, no stats |
| Season pass (“Breathing Path”) | Track with cosmetic + lore pages; free track exists |
| QoL ranks | Extra homes, warps, queue priority, name color |
| Event slot / Archive RP world | Paid seat for special events, not combat power |
| Hosting tip jar | Transparent monthly cost report |

### Never sold

| Forbidden | Why |
|-----------|-----|
| Ψ/Φ bonuses | P2W |
| Damage / cooldown / mastery boosts | P2W |
| Locked schools or endgame spells for cash | Paywall gameplay |
| Kit with overpowered gear | P2W |
| Pay-to-win crates with power rolls | Trust death |

### Rank sketch (QoL only)

| Rank | Cosmetics | Homes | Warps | Queue |
|------|-----------|-------|-------|-------|
| Visitor | — | 1 | 0 | normal |
| Adept (small) | 1 title | 2 | 1 | normal |
| Operator | school aura pack | 3 | 2 | priority |
| Archivist | lore title + unique trail | 4 | 3 | priority |

Prices: set after hosting cost is known; publish RUB and optionally Stars/USD via Boosty shop.

## Season structure (2–3 months)

1. **Hook** — lore letter + spawn build theme (school conflict / Φ anomaly)
2. **Mid** — event weekends (duels by school rules, seal puzzles)
3. **Finale** — temporary world boss or ritual (cosmetic rewards)
4. **Archive** — screenshot museum; soft reset or keep with decay rules

Align seasons with mod demos when possible (stream the finale).

## Technical checklist

- [ ] Hosting budget (RAM for NeoForge + view distance policy)
- [ ] Automatic backups (daily) + offsite copy weekly
- [ ] Anticheat / grief protection (as needed)
- [ ] Same Effecoria version as public Modrinth recommend
- [ ] Supporter early builds tested on a **staging** instance first
- [ ] Donate plugin/store only lists allowed products

## Go / no-go to public donate

**GO** if: uptime OK, mods respond, players stay for fun without shop.  
**NO-GO** if: mod still crashing, or community asks for P2W “like other servers.”
