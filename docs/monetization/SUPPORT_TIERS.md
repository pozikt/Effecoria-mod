## Tier table

| Tier | RU price (guide) | EN price (guide) | Benefits |
|------|------------------|------------------|----------|
| **Supporter** | 150–300 ₽/mo | $3–5/mo | Credits name, Discord role, WIP screenshots / design voices |
| **Initiate** | 500–700 ₽/mo | $7–10/mo | All above + early builds 7–14 days + private changelog + seasonal priority poll |
| **Operator** | 1200–2000 ₽/mo | $15–25/mo | All above + school cosmetics (particles, HUD frame, nametag) shared with official server when live |
| **Archivist** | high | high | All above + named lore fragment or NPC mention on server + bug triage priority |

### Non-negotiable

- Early access is **temporary** (7–14 days), then public.
- Never sell exclusive permanent combat power, Ψ discounts, or school unlocks behind paywall.
- Cosmetics and lore only for paid exclusive lasting value.
