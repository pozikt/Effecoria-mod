## Hard rules

1. Core magic loop stays free and self-sufficient.
2. No pay-to-win (damage, Ψ, school power for money).
3. Do not open paid tiers or server donate before the funnel is recommendable.
4. Register tax status on **first real payout**, not months early.
5. One paid layer at a time: support → server cosmetics → first DLC.

## Phase order

```
Phase 0  Stage I feel + brand channels
Phase 1  First fans → Boosty/Patreon + НПД + whitelist server
Phase 2  Public server + Operator cosmetics
Phase 3  First DLC after strong free-core reception
```
