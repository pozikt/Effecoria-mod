```markdown
# Effecoria

NeoForge **1.21.1** mod based on the [Effecoria](https://github.com/pozikt/Effecoria) universe (ЕТЭВ / Φ-field).

## Features
- School initiation (Elemental, Mental, Organic, Necromancy, Spatial, Corruption, Seals)
- Ψ (psi) & Φ (phi) resources with HUD
- Spell book + cast loop
- Breathing mastery & physical training hooks
- Block seal programming

## Free core policy
The magic loop stays free and self-sufficient. Optional support and story addons never sell raw power.

## Requirements
- Minecraft 1.21.1
- NeoForge (see version on this page)

## Links
- Lore encyclopedia
- Discord
- Support (Boosty / Patreon)
```
